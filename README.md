# ProofScope

ProofScope is a Proof-of-Skill prototype testing a context-transfer attack.

The prototype tests whether evidence authorized for one role and employer can be reused in another context.

## MVP flow

Home → Projects → Evidence → Choose context → Verify → Result → Human review

## Key rule

A context mismatch does not mean the student lacks ability. It means the evidence was not verified for the selected context.

The student controls sharing, and human review has final authority.
